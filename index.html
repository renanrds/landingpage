Modernização de ERP corporativo

Evolução de um ERP monolítico legado em Django (dezenas de módulos operacionais: compras, estoque, comercial, financeiro, RH, projetos, fiscal e outros) para uma stack desacoplada: backend Django + DRF, JWT e Celery; frontend SPA em React, Vite, Tailwind v4 e TypeScript. Integrações com ERPs externos, motores de workflow e bases legadas. Ambiente containerizado com PostgreSQL e Redis próprios, bootstrap via Docker e Makefile, com PoC de autenticação JWT e healthcheck (API + tela React).

Showcase público (módulos e funcionalidades, sem o código-fonte): erp-v2-showcase.

Administreino

Projeto pessoal — espaço para detalhar stack e decisões técnicas com mais profundidade. Plataforma full stack para criar, executar e acompanhar treinos de musculação, com experiência mobile-first e instalável como PWA. O usuário monta fichas com exercícios, séries, cargas e descansos; registra sessões em tempo real com cronômetro flutuante e acompanhamento de reps, carga e RPE; e visualiza evolução por dashboard e histórico com snapshots preservados ao longo do tempo.

Destaques: criação de treinos com IA (gerador de prompts + importação JSON), sugestão inteligente do próximo treino em programas divididos (A/B/C, PPL), geofencing para apps de academia (Wellhub/Totalpass) e pipeline CI/CD com deploy automatizado via GitHub Actions.

Plataforma multi-tenant de gestão

Sistema de gestão com isolamento por schema no PostgreSQL: cada empresa opera de forma independente, com SPA em React (Vite + Tailwind + TypeScript), API Django/DRF com JWT e chaves de integração por aplicação. Inclui ambientes de plataforma e tenant, Docker/Makefile para desenvolvimento, CI com testes e deploy com backup, migrations e healthcheck — produção via reverse proxy e túnel seguro.

Showcase público (sem o código-fonte): conexo-showcase.
